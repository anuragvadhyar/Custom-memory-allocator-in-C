# Custom Memory Allocator in C

This project is a simple implementation of a custom memory allocator in C. It demonstrates how dynamic memory management can be handled manually, similar to how `malloc` and `free` work under the hood.

## Files
- `main.c`: Example usage and test cases for the allocator.
- `mem_alloc.c`: Implementation of the memory allocation and deallocation functions.
- `mem_alloc.h`: Header file with function declarations and data structures.

## How to Build

To compile the project, run:

```
gcc main.c mem_alloc.c -o mem_alloc
```

## How to Run

After building, run the executable:

```
./mem_alloc
```

## Notes
- This allocator is for educational purposes and is not intended for production use.
- The code is written to be easy to read and modify for learning and experimentation.
